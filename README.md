## 📖 О проекте

**Game Settings Vault** — desktop-приложение для хранения и управления настройками видеоигр.

Приложение позволяет создавать библиотеку игр и сохранять для каждой игры несколько пресетов настроек.

Например, для одной игры можно создать:

- `1440p Ultra`
- `1440p Competitive`
- `1080p High FPS`
- `Ray Tracing`
- `Low Spec`

Каждый пресет содержит настройки изображения, графики, управления и производительности.

Проект разработан на **Python** с использованием **Flet**, **SQLAlchemy** и **SQLite**.

## 🏗️ Архитектура

Приложение построено с разделением ответственности между слоями:

```text
View
  │
  ▼
Controller
  │
  ├── Mapper
  ├── NotificationFactory
  │
  └── Repository
        │
        ▼
     Database
```

Основная логика работы приложения находится в контроллерах.
Репозитории отвечают за взаимодействие с базой данных, Mapper — за преобразование данных для компонентов представления,
NotificationFactory — за создание уведомлений, а View отвечает за отображение интерфейса и обработку пользовательских
действий.

## 🧠 Основные сущности

### Game

Представляет игру в библиотеке.

Содержит:

```text
Название
Описание
Обложку
Статус избранного
Дату создания
Список пресетов
```

### Preset

Представляет сохранённый набор настроек игры.

```text
Preset
├── DisplaySettings
├── GraphicsSettings
├── ControlSettings
├── PerformanceSettings
└── Notes
```

## 🗄️ База данных

Для хранения данных используется:

```text
SQLite
```

Работа с базой выполняется через:

```text
SQLAlchemy ORM
```

Связь основных моделей:

```text
Game
 │
 │ 1
 │
 │
 │ N
 ▼
Preset
```

Одна игра может содержать несколько пресетов.

При удалении игры связанные с ней пресеты также удаляются.

```text
+-------+---------------------+---------------------+

| user  | 07.10.2026 20:30:15 | 07.10.2026 23:42:08 |

```

